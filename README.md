# Minhas Skills

Coleção pessoal de skills para o Claude Code. Cada pasta é uma skill com um `SKILL.md`.

## Instalar

Instala todas as skills de uma vez no seu computador:

```bash
npx skills add arotadosmilagres-lgtm/silver-spork -g -a claude-code -y
```

Para usar uma skill específica, diga o nome dela no pedido. Exemplo: "usa a skill copywriting".

## 🎨 Design de sites e telas

|---|---|
