# Minhas Skills

Coleção pessoal de skills para o Claude Code. Cada pasta é uma skill com um `SKILL.md`.

## Instalar

```bash
npx skills add arotadosmilagres-lgtm/silver-spork -g -a claude-code -y
```

## Skills

| Skill | O que faz |
|---|---|
| `design-taste-frontend` | Cria e melhora sites com cara profissional. Cópia da [Taste Skill](https://github.com/Leonxlnx/taste-skill) (licença MIT, de Leonxlnx). |
| `ui-ux-pro-max` | Inteligência de UI/UX: páginas, componentes, cores, fontes, acessibilidade, layout responsivo. |
| `design` | Design completo: identidade de marca, logos, ícones, banners, apresentações. |
| `design-system` | Tokens de design (cores, espaçamentos, tipografia) e especificação de componentes. |
| `ui-styling` | Interfaces com shadcn/ui e Tailwind CSS. |
| `brand` | Voz da marca, identidade visual e guias de estilo. |
| `banner-design` | Banners para redes sociais, anúncios, capas de site e impressão. |
| `slides` | Apresentações em HTML com gráficos. |

As 7 skills acima de `ui-ux-pro-max` até `slides` são cópia da [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) (licença MIT, de Next Level Builder).
